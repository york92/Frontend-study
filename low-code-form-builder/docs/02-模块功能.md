# 02 模块功能

## 入口与全局

| 文件 | 职责 |
|---|---|
| `index.html` / `src/main.js` | 应用入口，挂载 `App` 并引入全局样式 |
| `src/App.vue` | 页面骨架：按 `state.mode` 切换 编辑（三栏）/ 预览 / JSON；注册全局快捷键（Ctrl/⌘+S 保存、Ctrl/⌘+Z 撤销、Shift+Z 重做、Delete 删除选中） |
| `src/styles.css` | 全局样式与设计变量（主色 `#3B5BDB`） |

## schema/（纯逻辑）

| 文件 | 职责 / 主要导出 |
|---|---|
| `registry.js` | `REGISTRY` 组件注册表（类型、分组、是否容器、子节点默认宽度、可配置项、默认属性）；`createNode(type)` 节点工厂；`uid()` |
| `logic.js` | `initialValue` 初始值；`isVisible` 显隐判断；`initModel` 生成表单数据模型；`validate` 校验（必填/规则/数字范围，跳过隐藏字段）；`collect` 收集提交数据（仅可见字段）；`RULES` 规则表 |

## store/builder.js（状态与动作）

状态 `state`：`form`（当前 Schema）、`forms`（列表）、`selectedId`、`mode`、`device`、`dragging/over`（拖拽）、`undoStack/redoStack`、`dirty`、`toast`。

动作：
- 树操作：`find` `allFields` `addNode` `addToSelection` `moveNode` `removeNode` `duplicateNode` `updateProp`
- 拖拽：`startDrag` `endDrag` `dropAt`
- 历史：`undo` `redo`
- 表单级：`init` `openForm` `createForm` `save` `publish` `replaceForm` `toast`

## components/

| 组件 | 职责 |
|---|---|
| `Toolbar.vue` | 表单切换/新建、模式切换（编辑/预览/JSON）、设备切换、撤销重做、保存、发布、重置 Mock、未保存提示 |
| `ComponentPanel.vue` | 组件库：按分组列出 `REGISTRY`，支持拖拽与点击添加 |
| `Canvas.vue` | 编辑区画布：可编辑标题/描述、根容器放置区、空状态提示、设备宽度 |
| `CanvasNode.vue` | 画布节点（递归）：选中态、类型标签、复制/删除工具条、拖拽源与放置目标、插入指示线 |
| `ConfigPanel.vue` | 右侧配置：字段属性（由 `config` 驱动动态生成）、表单属性、事件；含显隐条件与选项编辑 |
| `FieldControl.vue` | 控件层：按 `type` 渲染 10 种控件，`v-model` 双向绑定；编辑区传 `disabled` |
| `FieldBox.vue` | 字段外壳：标签（必填星标）、错误提示、标签位置（顶部/左侧） |
| `FormRenderer.vue` | 运行时渲染器：维护数据模型、校验、提交（调用 Mock API）、重置、结果回显 |
| `RenderNode.vue` | 渲染节点（递归）：处理显隐、容器/卡片/分割线/字段 |
| `JsonView.vue` | Schema 文本视图：编辑、复制、下载、应用到画布（含基本合法性检查） |
