# 03 使用说明

## 1. 安装与启动

```bash
npm install
npm run dev
```
打开 http://localhost:5173。生产构建：`npm run build`，产物在 `dist/`（纯静态，可部署到任意静态服务器；Mock 数据需随 `public/` 一并发布）。

## 2. 界面总览

- **顶栏**：选择/新建表单；切换 **编辑 / 预览 / JSON**；切换 桌面/平板/手机 宽度；撤销、重做、保存、发布。
- **左侧 组件库**：布局与基础控件。
- **中间 画布**：表单的编辑区，可直接修改标题与描述。
- **右侧 配置面板**：字段属性 / 表单属性 / 事件。

## 3. 搭建表单

1. **添加组件**：从左侧拖到画布；或点击组件，添加到当前选中位置（选中容器则放入容器，选中字段则插到其后）。
2. **排序与移动**：拖动画布中的组件，蓝色指示线显示插入位置；可拖入/拖出容器，不能把容器拖进自己里面。
3. **布局**：先放“两列栅格”，再把字段拖进去即自动各占一半；或选中字段后在右侧改“栅格宽度”（1/3、1/2、整行）。“分组卡片”可包住多行内容，容器之间可嵌套。
4. **选中**：点击组件；选中后右上角出现 **复制 / 删除**；也可按 `Delete`。点击画布空白处取消选中。
5. **配置字段**（右侧“字段属性”）：
   - 标签、字段标识（提交数据的 key，保持唯一）、占位提示、默认值
   - 必填、只读；校验规则（手机号 / 邮箱 / 网址）；数字最小/最大值
   - 选项（下拉、单选、多选：每行一个，**输入框失焦后生效**）
   - **显隐条件**：选择“依赖字段”并填写“等于”的值；例如依赖开关 `needLoan`，值填 `true`，则仅在开启“需要借款”时显示。
6. **表单属性**：标题、描述、标签位置（顶部/左侧）。**事件**：提交按钮文案、提交成功提示。

## 4. 预览与提交

切换到“预览”：可用桌面/平板/手机宽度检验响应式；点击提交会执行校验，通过后数据写入 Mock，并在表单下方回显提交内容（隐藏字段不会提交）。

## 5. JSON 导入导出

切换到“JSON”：可复制/下载当前 Schema；也可直接修改文本后点击“应用到画布”（需包含 `children` 数组）。应用后可撤销。

## 6. 保存、发布与 Mock 数据

- **保存**（Ctrl/⌘+S）：写入 Mock 存储（浏览器 localStorage），顶栏“未保存”提示消失。
- **发布**：保存并将状态置为“已发布”（Mock）。
- **重置 Mock**：清空本地数据，恢复 `public/mockData.json` 的初始内容。
- 修改初始数据：编辑 `public/mockData.json` 后，需点击“重置 Mock”（或清除站点数据）才会重新载入。

## 7. 快捷键

| 操作 | 快捷键 |
|---|---|
| 保存 | Ctrl/⌘ + S |
| 撤销 / 重做 | Ctrl/⌘ + Z / Ctrl/⌘ + Shift + Z |
| 删除选中组件 | Delete / Backspace（不在输入框内时） |

## 8. 常见问题

- **改了 mockData.json 没生效？** 数据已缓存到 localStorage，点“重置 Mock”。
- **端口被占用？** 修改 `vite.config.js` 中 `server.port`，或 `npm run dev -- --port 3000`。
- **安装依赖慢？** 可使用镜像：`npm install --registry=https://registry.npmmirror.com`。
- **想接真实后端？** 见《01-方案设计》第 6 节，只需改 `src/api/index.js`。
- **字段标识重复会怎样？** 同名字段共享同一个数据 key，请保持唯一（复制组件时系统会自动改名）。
