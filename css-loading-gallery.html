纯 CSS Loading 动画合集

一个单文件 HTML，集中展示多种不依赖 JavaScript、图片或第三方库的 CSS 加载动画。 保存后直接双击打开即可运行。

01 · Classic Spinner

使用 border + border-top-color + rotate 实现最经典的旋转加载。

border + transform: rotate()

02 · Bouncing Dots

三个圆点依次向上跳动，通过 animation-delay 制造错峰效果。

translateY + animation-delay

03 · Audio Bars

多个柱状条做纵向缩放，适合音频播放、语音识别和实时状态展示。

scaleY() + delay

04 · Rotating Square

小方块围绕中心轨道运动，同时使用反向 rotate 保持自身方向稳定。

rotate() + translateX()

05 · Double Ring

通过 ::before / ::after 构建两层环形结构，并让它们反向旋转。

pseudo-elements + double rotation

06 · Pulse

元素缩放、透明度和 box-shadow 同步变化，形成呼吸与脉冲效果。

scale + opacity + box-shadow

07 · Rotating Dots

八个圆点沿圆周排列，再让整个点阵持续旋转。

CSS variables + transform-origin

08 · Box-shadow Dots

只有一个 DOM 元素，利用 box-shadow 复制出另外两个圆点。

one element + box-shadow

09 · Conic Progress

conic-gradient 创建环形进度效果，适合仪表盘、进度环和数据可视化。

conic-gradient + animation

10 · Skeleton / Shimmer

使用线性渐变移动制造“扫光”效果，是现代 Web 应用非常常见的骨架屏加载方案。

linear-gradient + background-position

11 · Button Loading

实际项目中常见的按钮加载状态：按钮内容保持稳定，只替换为小型 spinner。

正在加载...
button state

12 · Glowing Dots

通过缩放、透明度和 box-shadow 做发光点阵，适合 AI / 科技风 UI。

scale + opacity + glow
Pure CSS · No JavaScript · No external dependencies
